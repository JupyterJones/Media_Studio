## 🗂️ File Descriptions & Technical Roles

### 1. Application & Scripts
* **[`app.py`](file:///home/jack/Desktop/scifi-writer_1/app.py)**:
  - Flask web server powering the graphical studio.
  - Exposes REST endpoints for markdown loading/saving, Ollama story generation, Kokoro speech synthesis, local LCM image generation, BGM scanning, and live video rendering progress tracking.
* **[`scifi_engine.py`](file:///home/jack/Desktop/scifi-writer_1/scifi_engine.py)**:
  - The brain of the project.
  - Contains regex parsers for storyboards, text sanitizers (removes unsupported glyphs, expands stardates to words), Kokoro CLI runner, local Stable Diffusion LCM loader (`diffusers`), PIL cyber HUD compositor, and FFmpeg filter chains for Ken Burns motion easing.
* **[`build_video.py`](file:///home/jack/Desktop/scifi-writer_1/build_video.py)**:
  - Command-line interface tool. Allows compiling any storyboard markdown file directly to MP4 with customizable BGM, volumes, and speeds.
* **[`build_v3_local.py`](file:///home/jack/Desktop/scifi-writer_1/build_v3_local.py)**:
  - Dedicated script for running 100% local Stable Diffusion generation using your local checkpoint (`dreamshaper_8LCM.safetensors`). Saves all outputs to `_v3` directories without overwriting existing files.
* **[`start_studio.sh`](file:///home/jack/Desktop/scifi-writer_1/start_studio.sh)**:
  - Quick launcher script. Checks that Ollama is running and boots `app.py` using your virtual environment Python.

### 2. Storyboard Markdown Specifications
* **[`template.md`](file:///home/jack/Desktop/scifi-writer_1/template.md)**:
  - The original storyboard provided for the project ("Aurora Rising"). Features 5 panels detailing the Kepler-62f expedition.
* **[`TEMPLATEv2.md`](file:///home/jack/Desktop/scifi-writer_1/TEMPLATEv2.md)**:

* **[`TEMPLATEv3.md`](file:///home/jack/Desktop/scifi-writer_1/TEMPLATEv3.md)**:
  - Dedicated storyboard file configured for 100% local Stable Diffusion generation targeting `science_v3.mp4`.

## ⚙️ Connected Local System Integrations

The studio is directly integrated with your existing workstation tools:

1. **Ollama LLM (`scifi-writer:1`)**:
   - Running at `http://127.0.0.1:11434`.
   - The studio's Web UI allows you to input any sci-fi concept or memory and receive a complete formatted storyboard.
2. **Kokoro TTS (`/home/jack/Desktop/Kokoro-TTS-Pause/`)**:
   - Model: `kokoro-v1.0.onnx` (325 MB)
   - Voices: `voices-v1.0.bin` (26 MB)

   - Utilizes `LCMScheduler` for rapid 4-step inference.
4. **Soundtracks & BGM (`/home/jack/Desktop/mp3/`)**:
   - Scans 15+ tracks including `Shadows-Anno_Domini_Beats.mp3`, `Sinister-Anno_Domini_Beats.mp3`, `GodFury-AnnoDominiBeats.mp3`, and `Future-Anno_Domini_Beats.mp3`.
5. **FFmpeg (`/usr/local/bin/ffmpeg`)**:
   - Hardware-accelerated 1080p H.264 video rendering with subpixel zoompan and audio stream mixing.
6. **Google Gemini Image API (`GEMINI_API_KEY`)**:
   - Integrated directly into the Director Studio UI ("✨ Generate with Gemini") to generate cinematic 16:9 images via `gemini-2.5-flash-image` whenever quota is enabled on your key.

## 🚀 How to Run the Applications

### Option A: Launch the Web Studio
```bash
cd /home/jack/Desktop/scifi-writer_1
./start_studio.sh
```
Open **`http://localhost:5055`** in your browser to:
- Edit storyboards or generate new ones with Ollama `scifi-writer:1`.
- Switch voices and synthesize Kokoro audio clips with one click.
- Generate or upload panel artwork.
- Select and preview background music tracks.
- Render videos and watch them in the built-in cinema player.

### Option B: Command-Line Render (CLI)
```bash
cd /home/jack/Desktop/scifi-writer_1

# Render TEMPLATEv2.md to science_v2.mp4
/home/jack/Desktop/Kokoro-TTS-Pause/venv/bin/python3 build_video.py \
  --markdown TEMPLATEv2.md \
  --output science_v2.mp4

# Run 100% Local Stable Diffusion Pipeline (V3)
/home/jack/Desktop/Kokoro-TTS-Pause/venv/bin/python3 build_v3_local.py

# Run Staacor News Pipeline (Ollama starcor-news:1 storyboard)
/home/jack/Desktop/Kokoro-TTS-Pause/venv/bin/python3 build_staacor_news.py
```

### Option C: Standalone Video Effects Post-Processing (CLI)
You can apply sci-fi visual effects to any completed video without external dependencies:
```bash
cd /home/jack/Desktop/scifi-writer_1

# List available presets (cyberpunk, scanlines, vhs, vignette, dust, thermal, holonet, noir)
python3 apply_effects.py --list

# Apply Holonet broadcast effect to Staacor News
python3 apply_effects.py --input staacor_news.mp4 --preset holonet --output staacor_news_holonet.mp4

# Apply Cyberpunk neon grading & vignette to Science V2
python3 apply_effects.py --input science_v2.mp4 --preset cyberpunk

# Chain custom effects
python3 apply_effects.py --input science_1.mp4 --effects scanlines,vignette
```

### Option D: Interactive Canvas Visual Effects Studio (Browser)
1. Start `./start_studio.sh` (or `python3 app.py`).
2. Navigate to **`http://localhost:5055/effects`** or click **"✨ VISUAL FX STUDIO"** in the top navigation.
3. 1-click load any video (`staacor_news.mp4`, `science_1.mp4`, `science_v2.mp4`, `science_v3.mp4`).
4. Toggle 17 layered real-time effects (Holographic orbit rings, light beams, CRT scanlines, retro VHS, cosmic dust, etc.) and tweak individual opacity sliders.
5. Record real-time video playback to WebM/MP4 directly into `exports/`.
